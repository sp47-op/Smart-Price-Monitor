# Task 3 submission checklist

Tick each item only after verifying it on your own machine.

## Mandatory
- [ ] Python 3.x environment created and documented
- [ ] Microsoft Playwright installed and Chromium launches
- [ ] `.env` configuration works; `.env` is not committed
- [ ] Logging visible in terminal and saved to `logs/automation.log`
- [ ] Exception path tested; browser/page close correctly
- [ ] Actual success screenshot saved
- [ ] README reviewed and setup instructions tested
- [ ] Browser launches and navigates to a page
- [ ] Form fields are filled and confirmation is validated
- [ ] Explicit waits are used (no arbitrary sleep-based synchronization)
- [ ] Output validated and errors handled
- [ ] Modular functions and meaningful names
- [ ] No unused files or hardcoded credentials

## Bonus
- [ ] Async Playwright
- [ ] Headless and headed modes
- [ ] CLI options
- [ ] CSV export
- [ ] PDF report
- [ ] Docker image builds and runs
- [ ] GitHub Actions workflow passes
- [ ] Unit tests pass locally
- [ ] SMTP notification tested with own credentials (optional)

## Submission deliverables
- [ ] GitHub repository URL checked
- [ ] README visible on GitHub
- [ ] 2–5 minute demo video recorded and link checked
- [ ] LinkedIn post published with actual repository/demo links

Do not mark a requirement complete until you have verified it. Online site availability, selectors, SMTP settings, Docker, and GitHub Actions may require environment-specific adjustments.
